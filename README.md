# 🧠 PhantasiAI

**PhantasiAI** is a multimodal AI research prototype integrating real-time signal processing and online optimization. 

> ⚠️ This repo contains several prototype versions. The current prototype, documentation, and requirements are located in API_Prototype/

---

## 🗂️ Project Structure

```
PhantasiAI/
├── API_Prototype/          # Current prototype
├── Prev_Modules/           # Individual modules from past prototypes
│   └── CEBRA/              # Classification module
│   └── GPBO/               # GP Bayesian Optimization module
│   └── RAG/                # Retrieval-Augmented Generation module
├── Prev_Prototypes/        # Past prototypes from 2024 and 2025 + documentation
│   └── 2024/               
│   └── 2025/               
│   └── 2025_v2/               
│   └── Docs/               # Project documentation (Old version)
│   └── requirements.txt    # List of Python dependencies for older versions              
└── README.md               # This file
```
